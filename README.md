# TreasureHunt
###
This is a treasure hunt event hosted on website as part of Vijnana 26, tech fest of KBSGCT. It has 8 levels, only 15 people will be promoted to level 5 and only 6 members will be promoted to level 7. Also it contains features like login, register, illegal level access blocking, etc.
## Features
- Login & Register
- Leaderboard
- Level promotion restriction according to count
- Block illegal access to higher levels
